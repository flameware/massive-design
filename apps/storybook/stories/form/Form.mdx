여러 `Field`를 묶어 한 번에 제출하는 `<form>`이에요. 제출값을 모아 주고, 서버가
돌려준 필드별 오류를 해당 필드 아래에 보여 줘요.

## 언제 쓰는가

- 로그인이나 회원가입처럼 여러 `Field`를 모아 한 번에 제출할 때.
- 서버가 필드별 오류를 돌려주고, 그것을 해당 필드 아래에 보여 줘야 할 때.

## 언제 쓰지 않는가

- 제출이 없는 필터나 검색창처럼 묶기만 필요하다면 `<div>`로 충분해요.
- 폼 라이브러리(React Hook Form, TanStack Form)와의 연결은 `Field`가
  담당해요. `Form`은 그 라이브러리를 몰라요.

## 사용법

```tsx
import { Button } from "@flameware/ui/button"
import { Field } from "@flameware/ui/field"
import { Form } from "@flameware/ui/form"
import { Input } from "@flameware/ui/input"

<Form onFormSubmit={(values) => save(values)}>
  <Field.Root name="title" required>
    <Field.Label>제목</Field.Label>
    <Input />
    <Field.Error match="valueMissing">필수 항목입니다</Field.Error>
  </Field.Root>
  <Button type="submit">저장</Button>
</Form>
```

`onFormSubmit`은 필드 이름과 값을 짝지은 객체를 바로 받아요. 각 컨트롤의
`required`나 `pattern` 같은 브라우저 검증을 통과했을 때만 불려요. 브라우저의
원래 `<form>` 이벤트가 필요하면 `onSubmit`을 쓰세요.

### 서버 오류 보여 주기

`errors`에는 필드 이름과 오류 문자열을 짝지은 객체를 넘겨요. 같은 이름의
`Field.Root` 아래에 있는 `Field.Error`가 `match` 없이도 그 문자열을 자동으로
보여 줘요. 이미 쓰고 있는 이메일처럼 서버만 알 수 있는 오류에 쓰세요.
