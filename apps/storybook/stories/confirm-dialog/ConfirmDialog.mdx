되돌릴 수 없는 결정을 확인받는 모달을 호출 한 번으로 그려요. 제목, 설명,
확인/취소 버튼, 위험 표시, 로딩 상태를 한데 묶어 놓은
[AlertDialog](?path=/docs/overlays-alertdialog--docs) 프리셋이에요.

## 언제 쓰는가

- 제목, 설명, 확인/취소 버튼 둘만 있으면 되는 삭제나 되돌리기 확인.

## 언제 쓰지 않는가

- 확인 버튼이 둘 이상이거나, 본문에 폼이나 목록처럼 설명 한 줄을 넘는 내용이
  들어가면 [AlertDialog](?path=/docs/overlays-alertdialog--docs)를 직접
  조립하세요. `AlertDialog`의 파트는 그대로 남아 있어서 내려가는 데 드는
  비용이 없어요.

## 사용법

<Canvas of={ConfirmDialogStories.Playground} />

```tsx
import { Button } from "@flameware/ui/button"
import { ConfirmDialog } from "@flameware/ui/confirm-dialog"

<ConfirmDialog
  trigger={<Button variant="destructive">거래 삭제</Button>}
  title="거래를 삭제할까요?"
  description="삭제한 거래는 되돌릴 수 없습니다."
  tone="danger"
  confirmLabel="삭제"
  onConfirm={() => deleteTransaction()}
/>
```

`trigger`를 생략하면 트리거를 그리지 않아요. 표의 행 메뉴처럼 트리거가
다이얼로그 밖에 있으면 `open`과 `onOpenChange`로 직접 여세요.

`tone`은 확인 버튼의 색이에요. 기본값은 `neutral`이고, 삭제처럼 되돌릴 수 없는
동작에는 `danger`를 주면 확인 버튼이 `destructive` 색으로 칠해져요.

### 로딩 상태

`onConfirm`이 Promise를 반환하면 그 동안 확인 버튼이 잠기고 스피너가 돌아요.
빠르게 두 번 눌러도 `onConfirm`은 한 번만 불려요. Promise가 성공하면
다이얼로그가 닫히고, 실패하면 열린 채로 남아 다시 시도할 수 있어요.

취소는 로딩 중에도 잠기지 않아요. Esc와 취소 버튼 둘 다 그대로 닫혀요.

## 주의할 점

### 여러 건을 한 번에 지울 때는 취소에 포커스를 주세요

열릴 때 포커스는 기본적으로 확인 버튼으로 가요. 표에서 여러 행을 고르고 한
번에 지우는 경우에는 `initialFocus="cancel"`을 주세요. 무심코 누른 Enter
하나가 고른 것 전부를 지우면 안 되기 때문이에요.

```tsx
<ConfirmDialog
  trigger={<Button variant="destructive">선택 삭제</Button>}
  title={`선택한 ${count}건을 삭제할까요?`}
  description={`선택한 거래 ${count}건을 삭제합니다. 이 작업은 되돌릴 수 없습니다.`}
  tone="danger"
  confirmLabel="삭제"
  initialFocus="cancel"
  onConfirm={() => deleteMany(ids)}
/>
```

<Canvas of={ConfirmDialogStories.KeyboardCancelFocus} />

`tone="danger"`를 줘도 포커스는 확인 버튼에 그대로 있어요. 단건 삭제도 대개
`tone="danger"`이고, 그 경우에는 방금 사용자가 지목한 것 하나를 지우는
것이라 확인이 먼저 오는 편이 맞아요. 위험을 가르는 것은 색이 아니라 건수라서,
그것을 아는 호출부가 값을 골라요.

## 키보드

`AlertDialog`와 같은 포커스 가두기와 Esc 닫기가 그대로 적용돼요. 다른 점은
열릴 때의 포커스 위치뿐이에요.

## 배경

DS는 원래 프리셋을 두지 않기로 했고, 이 컴포넌트가 그 방침을 처음 바꿨어요.
같은 조립이 앱 네 파일에서 그대로 반복된 것이 근거예요. 프리셋은 파트 조립을
대신할 뿐 파트를 가리지 않아서, `AlertDialog`는 그대로 남아 있어요. 두 번째
프리셋은 같은 조립이 세 곳 이상에서 반복될 때만 열어요.
