라이트와 다크를 오가는 버튼 하나예요. 보통 앱 헤더에 하나만 놓아요.

## 언제 쓰는가

- 앱 헤더나 설정 메뉴에서 라이트와 다크를 바꾸는 곳.

## 언제 쓰지 않는가

- 고를 값이 셋 이상이면 쓰지 마세요. 라이트, 다크, 시스템처럼 셋이면
  [Menu](?path=/docs/overlays-menu--docs)로 고르게 하세요. `ThemeToggle`은 두 값
  사이만 오가요.

## 사용법

`ThemeToggle`은 테마 상태를 스스로 갖지 않아요. `theme`과 `onThemeChange` 두
prop만 받기 때문에 `next-themes`를 쓰든 직접 만든 상태를 쓰든 그대로 꽂을 수
있어요.

```tsx
import { useTheme } from "next-themes"
import { ThemeToggle } from "@flameware/ui/theme-toggle"

function Header() {
  const { resolvedTheme, setTheme } = useTheme()
  return (
    <ThemeToggle
      theme={resolvedTheme === "dark" ? "dark" : "light"}
      onThemeChange={setTheme}
    />
  )
}
```

## 주의할 점

### `dark` 클래스는 앱이 붙여요

`ThemeToggle`은 `<html>`의 클래스를 만지지 않아요. `next-themes`나 그 역할을
하는 앱 코드가 `dark` 클래스를 붙여야 화면 색이 실제로 바뀌어요. DS의 라이트와
다크 전환은 이 클래스 하나로 돌아가요.

## 배경

`Toggle`을 쓰지 않고 `Button`에 `aria-pressed`만 얹은 이유는 이 버튼이 폼 값이
아니라 두 값을 번갈아 바꾸는 동작이기 때문이에요. 아이콘 버튼 하나를 위해
컴포넌트 사이에 새 의존을 더하지 않겠다는 판단이기도 해요
([ADR-0017](https://github.com/flameware/massive-design/blob/main/docs/adr/0017-dependency-weight-is-a-floor-cost.md)).
