# 브랜드 색 입히기

브랜드 색 하나를 넘기면 DS의 강조색(`accent`)이 모두 그 색으로 바뀌어요.
버튼 primary, 링크, 포커스 링, 강조 텍스트가 여기에 해당해요. 아무것도 하지
않으면 DS 기본 브랜드 색(`#0f5fed`)이 그대로 쓰여요.

## 사용법

### 1. 패키지 설치

```sh
bun add @flameware/tokens
```

### 2. 브랜드 색으로 CSS 만들기

`createBrandOverride`에 브랜드 색을 넘기면 CSS 문자열이 나와요. hex뿐 아니라
`oklch(...)` 같은 CSS 색 표기도 쓸 수 있어요.

브랜드 색은 배포할 때마다 바뀌지 않으니, 빌드 단계에서 한 번 파일로 저장해
커밋하면 돼요.

```ts
import { writeFileSync } from "node:fs"
import { createBrandOverride } from "@flameware/tokens/ramp"

const css = createBrandOverride("oklch(0.52 0.11 155)") // 녹색 브랜드
writeFileSync("app/brand.css", css)
```

### 3. `tokens.css` 다음에 불러오기

```css
/* app/globals.css */
@import "tailwindcss";
@import "@flameware/tokens/tokens.css";
@import "./brand.css"; /* 반드시 tokens.css 다음에 둬요 */
```

만들어진 CSS는 `:root`(라이트)와 `.dark`(다크) 블록에서
`--ds-palette-brand-*` 변수를 다시 선언해요. 같은 이름의 변수는 나중에 선언한
값이 적용되므로, `brand.css`가 `tokens.css`보다 앞에 오면 색이 바뀌지 않아요.

## 주의할 점

### 너무 밝은 색은 에러가 나요

브랜드 색 위의 흰 글자(`fg.on-solid`)가 잘 읽히지 않을 만큼 밝은 색을 넘기면
`createBrandOverride`가 에러를 내요. 경고만 출력하고 넘어가지 않으니 빌드
단계에서 바로 알 수 있어요.

```ts
createBrandOverride("#eab308")
// Error: createBrandOverride: 브랜드 색의 대비가 기준에 못 미쳐서 글자와 테두리가 잘 보이지 않아요.
//   light fg.accent ↔ bg.canvas 대비 2.81, 기준 4.5
//   …
//   light fg.on-solid ↔ bg.accent.solid 대비 1.92, 기준 4.5
//   …
// 브랜드 색을 조금 어둡게 조정한 뒤 다시 실행해 보세요.
```

에러 메시지는 어떤 색 조합이 기준에 얼마나 못 미쳤는지 알려 줘요. 위 예시는
라이트 모드에서 흰 글자와 브랜드 색의 대비가 1.92:1이라 기준인 4.5:1보다
낮다는 뜻이에요. 브랜드 색을 조금 어둡게 조정한 뒤 다시 실행해 보세요.

DS가 기본 색을 검사할 때와 같은 조합, 같은 기준으로 검사해요.

| 검사하는 조합 | 기준 |
| --- | --- |
| 강조 배경(`bg.accent.solid`) 위의 흰 글자(`fg.on-solid`) | 4.5:1 |
| 강조 텍스트와 링크(`fg.accent`, `fg.link`)와 그 아래 배경 | 4.5:1 |
| 강조 테두리와 포커스 링(`border.accent`, `border.focus`)과 배경 | 3:1 |
| 옅은 강조 배경(`bg.accent.muted`)과 배경 | 1.35:1 |

### 모드마다 다른 색은 넘길 수 없어요

브랜드 색은 하나만 받아요. 라이트 모드와 다크 모드의 색은 모두 이 색 하나에서
만들어져요. 이유는 아래 [배경](#배경)에 있어요.

### DS에 없는 새 색이 필요하다면

수익과 손실 색처럼 DS에 없는 색이 필요하면
[Foundations/자기 패밀리 만들기](?path=/docs/foundations-자기-패밀리-만들기--docs)의
`createRamp`를 쓰세요. 두 함수는 이렇게 달라요.

| | `createBrandOverride` | `createRamp` |
| --- | --- | --- |
| 하는 일 | DS의 브랜드 색을 바꿔요 | 앱 전용 새 색을 만들어요 |
| 만들어지는 변수 | `--ds-palette-brand-{mode}-{step}` | `--{prefix}-{step}` |
| 대비 검사 | 자동으로 하고, 기준에 못 미치면 에러가 나요 | 하지 않아요. `contrastRatio`로 직접 확인해요 |
| 받는 색 | CSS 색 표기 | hex(`#rrggbb`) |

## 배경

DS는 브랜드 색 하나로 라이트 모드용과 다크 모드용 12단계 색 배열(램프)을
각각 만들어요. 넘긴 색은 두 배열 모두 9단계에 그대로 들어가서, 9단계는 어느
모드에서나 같은 색이에요. 모드마다 다른 색을 받으면 이 규칙을 지킬 수 없어서
브랜드 색은 하나만 받아요.

대비 검사를 `createBrandOverride`에서만 강제하는 이유는 DS 컴포넌트 전체가 이
색을 버튼, 링크, 포커스 링에 쓰기 때문이에요.

전체 API는
[`@flameware/tokens` README](https://github.com/flameware/massive-design/blob/main/packages/tokens/README.md#브랜드-색으로-ds-강조색-바꾸기)에
있어요.
