# 타이포

글자 크기는 Tailwind 기본 이름(`text-sm`, `text-3xl`)을 그대로 써요. 새로
외울 이름은 없고, 줄 높이와 자간만 한국어 본문에 맞게 조정해 두었어요.

## 사용법

```tsx
<p className="text-sm">본문</p>
<h1 className="text-3xl">제목</h1>
```

<TypeScale />

### 기본 서체

기본 서체는 Pretendard이고, `--font-sans` 변수 하나로 들어와요.

```css
font-family: var(--font-sans);
```

## 배경

줄 높이는 크기마다 다르지 않고 세 단계로 묶여 있어요. 본문(`xs`, `sm`,
`base`, `lg`)은 1.6, 중간(`xl`, `2xl`)은 1.4, 제목(`3xl` 이상)은 1.25예요.
한국어는 라틴 문자보다 글자 밀도가 높고 받침이 세로 공간을 더 써서 값을
넉넉히 잡았고, 크기마다 다른 값을 주면 같은 문단 안에서 줄 높이가 튀어요.
자간은 큰 글자만 좁히는데(중간 −0.01em, 제목 −0.02em), 본문 자간을 음수로
주면 한글 낱글자가 뭉쳐요.
