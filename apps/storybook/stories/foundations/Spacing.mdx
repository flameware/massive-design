# 간격

간격은 4px 배수 하나로 만들어져요. `p-3`은 12px, `gap-4`는 16px이에요. 외워야
할 단계 이름은 없어요.

## 사용법

```tsx
<div className="flex gap-3 p-4">…</div>
```

`--spacing`(4px)에 배수를 곱해 값이 만들어지므로 아래 표에 없는
배수(`gap-1.5` 같은)도 그대로 쓸 수 있어요.
