# 색

DS의 색은 `bg-surface`, `text-default` 같은 유틸리티 클래스로 써요. 라이트와
다크는 이 이름 안에서 갈리니 앱이 모드별로 클래스를 나눌 필요가 없어요.

## 사용법

### 1. CSS 불러오기

```css
/* app/globals.css */
@import "@flameware/ui/styles.css";
```

### 2. 유틸리티 이름 쓰기

```tsx
<div className="bg-surface text-default border border-default">…</div>
```

쓸 수 있는 이름은 아래 표가 전부예요. 이 문서 위쪽 툴바의 Theme 스위치를
바꾸면 스와치가 지금 켜진 모드의 실제 값으로 다시 그려져요.

<ColorTable />

### 배경색은 두 갈래예요

배경 토큰은 두 갈래예요. 하나는 무언가를 그 위에 올리는 바탕이고(`bg-canvas`,
`bg-surface`, `bg-subtle`, `bg-inset`, `bg-overlay`), 다른 하나는 그 바탕 위에
얹는 덩어리예요(`bg-<family>-soft`, `bg-<family>-muted`,
`bg-<family>-solid`).

## 주의할 점

### `bg-subtle`과 `bg-inset`은 같은 색이에요

두 이름은 같은 값을 가리켜요. 다크에서는 `bg-overlay`와 `bg-neutral-soft`까지
넷이 같아요. 의도한 별칭이라서 이 이름들 사이를 바꿔도 화면은 달라지지
않아요. 이름을 따로 둔 것은 앱이 어떤 의도로 그 색을 골랐는지 코드에 남기기
위해서예요. 바탕을 눈에 보이게 나누려면 색 대신 테두리, 그림자, 여백을
쓰세요.

### `-soft`는 조용한 바탕 위에서 보이지 않아요

`bg-<family>-soft`와 `bg-subtle`은 팔레트에서 같은 밝기 단계라 대비가
1.00:1이에요. 덩어리가 눈에 보여야 하면 `bg-<family>-muted`를 쓰세요.

### `-muted` 위의 글자는 `text-default`로 두세요

`bg-<family>-muted` 위에서는 같은 계열의 유채색 글자(`text-<family>`)가 대비
기준(AA)을 넘지 못해요. 이 단계 위의 글자는 `text-default`로 두세요.

### 다크에서 테두리 색은 반투명이에요

`border-default`와 `border-subtle`은 라이트에서 불투명한 neutral 단계예요.
다크에서는 흰색에 투명도를 준 값이에요(`border-default` 10%, `border-subtle`
5%). 같은 이름이지만 모드에 따라 값의 종류가 달라져요. `border-subtle`은
`border-default`보다 바탕에 한 겹 더 가까워서 차트 격자, 표의 행 구분선,
비활성 구획선이 이 색을 써요.

이 차이는 스와치 아래 hex 표시로는 보이지 않아요. `<canvas>`에 색을 직접
그리려고 `getComputedStyle`로 값을 읽는다면 다크에서 알파 채널을 버리면 안
돼요. 버리면 격자가 100% 흰색으로 그려져요. `rgba()` 문자열이나 알파를 포함한
hex(`#rrggbbaa`)를 그대로 옮기거나, `color-mix`로 실제 바탕 위에 합성한 뒤
픽셀을 읽으세요.

### hover와 pressed는 색 이름으로 찾을 수 없어요

hover와 pressed는 색 토큰이 아니라 `color-mix`로 얹는 반투명 층이라 위 표에
없어요. 어떻게 그려지는지는
[Actions/Button](/?path=/docs/actions-button--docs)의 "상태" 절에 있어요.

## 배경

라이트와 다크가 갈리는 곳은 semantic 층 하나예요. 팔레트
변수(`--ds-palette-*`)는 devtools에서 값을 추적할 때만 쓰고 `@theme`에
등록되지 않아요. 같은 `default`, `accent`, `danger` 이름이 `bg`, `text`,
`border` 셋에 따로 있어서, 이름이 겹쳐 충돌하지 않도록 역할별
변수(`--background-color-*`, `--text-color-*`, `--border-color-*`)가
`--color-*`보다 먼저 해석돼요.

`-muted` 단계는 바탕에 대해 1.35:1 이상을 유지하고, 그 단계 번호가 라이트 7,
다크 6으로 서로 달라요. 한 번호로 맞추면 한쪽 모드가 이 하한 아래로 내려가요.
대비 검사는 패밀리 5종과 바탕 5종을 두 모드에서 모두 재요.
