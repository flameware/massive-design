# 라이트 · 다크

다크 모드는 `dark` 클래스 하나로 전환돼요. `<html>`이나 그 아래 조상 요소에
이 클래스를 걸고 떼면 돼요. 앱이 `next-themes`를 쓰고 있다면 그대로 붙어요.

## 사용법

```tsx
// next-themes
<ThemeProvider attribute="class">…</ThemeProvider>
```

토큰 CSS의 `@custom-variant dark`가 그 클래스를 읽어요.

```css
@custom-variant dark (&:where(.dark, .dark *));
```

### Storybook에서 확인하기

이 문서 위쪽 툴바의 Theme 스위치로 바로 전환돼요.
[Foundations/색](/?path=/docs/foundations-색--docs)의 스와치가 지금 켜진
모드의 실제 값으로 그려져요.

## 주의할 점

### 같은 변형을 직접 만든다면 선택자를 그대로 쓰세요

`&:is(.dark *)`로 쓰면 `dark` 클래스가 걸린 요소 자신이 다크 스타일을 받지
못해요. `*` 하위 선택자가 그 요소 자신은 잡지 못하기 때문이에요. 앱에서 같은
변형을 선언할 때도 `&:where(.dark, .dark *)`를 그대로 쓰세요.

### 문서 껍데기는 라이트로 고정이에요

사이드바와 헤더는 Theme 스위치를 바꿔도 라이트로 남아요. 문서를 읽는 화면과
컴포넌트를 보는 화면을 나누기 위해서예요.

## 배경

팔레트 변수(`--ds-palette-*`)는 라이트용과 다크용 두 벌이 이미 있고, semantic
변수가 그중 하나를 가리켜요. 모드에 따라 값이 갈리는 곳은 이 semantic 층
하나예요. `.dark`는 semantic 변수 36개를 전부 다시 선언하는데, 일부만 다시
선언했더니 중첩된 하위 트리에서 일부가 라이트로 남는 결함이 났었어요([#35](https://github.com/flameware/massive-design/issues/35)).
