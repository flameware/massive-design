`lucide-react` 아이콘을 DS의 크기에 맞춰 그려요. 아이콘 함수를 `icon` prop으로
넘기면 돼요.

## 사용법

`lucide-react`는 선택 peer 의존성이라 Icon을 쓰는 앱만 설치하면 돼요.

```sh
bun add lucide-react
```

```tsx
import { Icon } from "@flameware/ui/icon"
import { Save } from "lucide-react"

<Icon icon={Save} size="md" />
```

## 크기

`size`는 세 값이고 각각 글자 크기와 짝지어져 있어요. `sm`은
`text-sm`(14px), `md`는 `text-base`(16px), `lg`는 `text-lg`(18px)예요.
Button이 자기 아이콘에 쓰는 기본 크기도 16px이라 글자와 나란히 놓으면 높이가
맞아요.

## 주의할 점

### 아이콘만으로는 뜻이 전달되지 않아요

Icon은 `aria-hidden`이 기본이라 화면 낭독기가 읽지 않아요. 뜻을 전하는 이름은
언제나 Icon 밖에 두세요. 아이콘만 보이는 버튼이라면 감싸는 요소에
`aria-label`을 주세요.

## 배경

Icon은 Card, Alert와 같은 자체 스타일 컴포넌트라 서버 컴포넌트로 남아
있어요(`"use client"`가 없어요). 덕분에 `icon={Save}`처럼 넘기는 lucide 아이콘
함수를 서버 컴포넌트에서도 그대로 쓸 수 있어요. `lucide-react`를 선택
의존성으로 둔 근거는
[ADR-0017](https://github.com/flameware/massive-design/blob/main/docs/adr/0017-dependency-weight-is-a-floor-cost.md)에
있어요.
