누른 상태가 남는 버튼이에요. 즐겨찾기, 굵게나 기울임 같은 서식 버튼, 사이드바
펼치기에 써요.

## 언제 쓰는가

- 켜고 끄기 하나. 즐겨찾기, 서식 버튼, 사이드바 펼치기가 여기에 해당해요.
- 혼자 쓰이는 토글 하나. 여럿을 한 판으로 묶고 화살표로 옮겨 다니게 하려면
  `ToggleGroup`을 쓰세요.

## 언제 쓰지 않는가

- 누르면 바로 무언가 일어나고 상태가 남지 않는다면 `Button`이에요.
- 여럿 중 하나 또는 여럿을 화살표로 옮겨 고른다면 `ToggleGroup`이에요.

## 크기

`size` 옵션은 `sm`, `md`, `lg` 세 가지이고 기본은 `md`예요. 높이는 차례로
32px, 36px, 40px이에요.

<Canvas of={ToggleStories.Sizes} />

값 이름과 높이가 `Button`의 `size`와 같아서, 같은 `size`를 준 `Button`과 한 줄에
두면 높이가 맞아요. `md`는 `Input`, `Select` 같은 입력 컨트롤의 높이(36px)와도
같아요. 여러 컨트롤을 한 줄에 둔 예시는 `ToggleGroup` 문서의 크기 절에 있어요.

`ToggleGroup` 안에 넣으면 `Toggle`에 준 `size`는 쓰이지 않고, 그룹의 `size`를
따라요. 그룹 안에서는 테두리와 안쪽 여백만큼 작아져서, 그룹 바깥의 높이가 위
값과 같아져요.

## 배경

Base UI Toggle 위에 색과 치수만 입혔어요. Base UI Toggle은 Checkbox나 Select와
달리 스스로 폼에 값을 내지 않아서, `name`을 받으면 지금 눌린 값을 그대로
따라가는 숨은 입력 하나를 곁에 세워요.

`md`의 높이는 0.7.0에서 32px에서 36px로, `sm`은 약 24px에서 32px로 바뀌었어요.
같은 이름의 컨트롤이 한 줄에서 같은 높이를 갖게 하려는 변경이에요
([ADR-0027](https://github.com/flameware/massive-design/blob/main/docs/adr/0027-control-height-is-shared-and-a-group-bears-it-on-its-outside.md)).

`size`는 이 컴포넌트의 옵션이에요. 화면 전체의 밀도를 한 번에 낮추는 기능은
제공하지 않아요([ADR-0023](https://github.com/flameware/massive-design/blob/main/docs/adr/0023-second-generation-base-ui.md)
§11).
