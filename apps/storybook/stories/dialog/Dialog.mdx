화면 가운데에 떠서 본문을 가리는 모달이에요. 비밀번호 변경이나 짧은 폼처럼
한 가지 일에 집중해야 할 때 써요.

## 언제 쓰는가

- 데스크톱에서 본문 흐름을 끊고 집중을 요구하는 작업. 비밀번호 변경, 짧은
  폼이 여기에 해당해요.
- 화면 폭이 768px 미만이면 같은 내용을
  [Drawer](?path=/docs/overlays-drawer--docs)로 여세요. 어느 쪽을 열지는 앱이
  정해요. DS는 화면 폭을 보고 자동으로 바꾸지 않아요.

## 언제 쓰지 않는가

- 되돌릴 수 없는 결정을 확인받을 때는
  [AlertDialog](?path=/docs/overlays-alertdialog--docs)를 쓰세요. 삭제나
  탈퇴처럼 확인과 취소 중 하나를 꼭 골라야 하는 경우예요.
- 사용자를 멈춰 세울 필요가 없는 알림은
  [Toast](?path=/docs/feedback-toast--docs)를 쓰세요.

## 사용법

파트를 조립해서 써요. 이름은 Base UI 문서와 하나씩 같아요. `Trigger`와
`Close`는 스타일이 없으니 `render`로 `Button`을 넘기세요.

<Canvas of={DialogStories.Playground} />

```tsx
<Dialog.Root>
  <Dialog.Trigger render={<Button variant="outline">비밀번호 변경</Button>} />
  <Dialog.Portal>
    <Dialog.Backdrop />
    <Dialog.Viewport>
      <Dialog.Popup>
        <Dialog.Close />
        <Dialog.Title>비밀번호 변경</Dialog.Title>
        <Dialog.Description>현재 비밀번호와 새 비밀번호를 입력하세요.</Dialog.Description>
        {/* ...폼, 취소/저장 버튼 */}
      </Dialog.Popup>
    </Dialog.Viewport>
  </Dialog.Portal>
</Dialog.Root>
```

### 제목 아래 간격과 버튼 줄

`Header`와 `Footer`가 레이아웃만 담당해요. `Header`는 `Title`(과
`Description`) 다음 세로 간격을, `Footer`는 오른쪽 정렬한 버튼 줄을 그려요.
모바일에서는 버튼이 세로로 쌓이면서 주 동작이 위로 올라와요. 직접
`mt-4 flex justify-end gap-2`를 짜지 않아도 돼요.

## 키보드

나가지 않아요. Esc를 누르면 닫히고 포커스가 트리거로 돌아와요. 아래 스토리가

## 배경

Base UI `Dialog` 위에 배경, 테두리, 그림자만 입혔어요. 포커스 가두기, 스크롤
잠금, Esc 닫기는 Base UI가 처리해요.

`Header`와 `Footer`는 Base UI에 대응하는 파트가 없어서 DS가 더한
레이아웃 그룹이에요.
