가운데 뜨는 모달. Base UI `Dialog` 위에 표면(배경·테두리·그림자)만 칠한다 — 포커스 트랩·스크롤 잠금·Esc 닫기는 Base UI가 진다.

## 언제 쓰는가

- 데스크톱에서 본문 흐름을 끊고 집중을 요구하는 작업 — 비밀번호 변경, 짧은 폼.
- 768px 미만에서는 같은 자리에 [Drawer](?path=/docs/overlays-drawer--docs)를 쓴다. 어느 쪽을 열지는 이 패키지가 정하지 않는다 — 앱이 자기 `useIsMobile`로 고른다.

## 언제 쓰지 않는가

- **되돌릴 수 없는 결정의 확인.** 삭제·탈퇴처럼 명시적 선택만 닫아야 하는 자리는 [AlertDialog](?path=/docs/overlays-alertdialog--docs)다.
- **알림.** 사용자 행동을 막지 않아도 되면 Toast(Phase 2)다.

## 조립

네임스페이스형이다(ADR-0023 §5) — Base UI 문서와 파츠 이름이 1:1이다. `Trigger`와 `Close`는 일부러 스타일이 없다: Button처럼 `render`로 조립한다.

<Canvas of={DialogStories.Playground} />

```tsx
<Dialog.Root>
  <Dialog.Trigger render={<Button variant="outline">비밀번호 변경</Button>} />
  <Dialog.Portal>
    <Dialog.Backdrop />
    <Dialog.Viewport>
      <Dialog.Popup>
        <Dialog.Close />
        <Dialog.Title>비밀번호 변경</Dialog.Title>
        <Dialog.Description>현재 비밀번호와 새 비밀번호를 입력하세요.</Dialog.Description>
        {/* ...폼, 취소/저장 버튼 */}
      </Dialog.Popup>
    </Dialog.Viewport>
  </Dialog.Portal>
</Dialog.Root>
```

`Header`·`Footer`는 Base UI에 대응 파트가 없는 순수 레이아웃 그룹이다(#293) — `Title`(+`Description`) 다음 세로 간격과, 우측 정렬 버튼 줄(모바일에서는 `flex-col-reverse`로 주 동작이 위로 온다)을 대신 진다. 소비처가 반복해서 손으로 짜던 `mt-4 flex justify-end gap-2`가 이 자리다.
