불러오는 동안 내용 대신 보여 주는 회색 틀이에요. 거래 카드나 목록 행처럼 최종
레이아웃을 미리 아는 곳에서 화면이 덜컹거리는 것을 줄여 줘요.

## 언제 쓰는가

- 불러온 뒤의 레이아웃을 미리 아는 로딩 구간에 쓰세요.

## 언제 쓰지 않는가

- 레이아웃이 없는 짧은 대기에는 [Spinner](?path=/docs/feedback-spinner--docs)를
  쓰세요. 버튼 안이나 전체 화면 오버레이가 여기에 해당해요.

## 사용법

모양은 `className`으로 정해요. Skeleton 자신은 크기도 모서리도 정하지 않아요.

```tsx
<Skeleton className="h-4 w-32" />        {/* 한 줄 */}
<Skeleton className="size-10 rounded-full" /> {/* 원 */}
```

### 감싸는 영역이 이미 로딩을 알린다면

Skeleton은 기본으로 `role="status"`와 `aria-busy="true"`를 스스로 내요. 감싸는
영역이 이미 같은 선언을 하고 있다면 `announce={false}`를 주세요. role도
`aria-busy`도 접근성 이름도 내지 않는 평범한 `div`로 남아서, 스크린 리더가 같은
로딩을 두 번 읽지 않아요.

## 주의할 점

### 여러 개를 늘어놓을 때는 이름을 하나만 주세요

대표 하나에만 `aria-label`을 의미 있게 주고 나머지는 기본값("불러오는 중")을
그대로 두세요. 전부에 이름을 주면 스크린 리더가 같은 말을 반복해요.

### `aria-label`에 가짜 내용을 넣지 마세요

`aria-label`은 무엇을 불러오는 중인지만 말해요. 아직 오지 않은 실제 내용을
흉내 내지 마세요.

## 배경

Base UI에 대응하는 컴포넌트가 없어서 DS가 직접 만들었어요.

`announce`를 옵션으로 연 이유는 이 회색 틀이 보통 여러 개씩 놓이기
때문이에요. Spinner가 `aria-hidden="true"`로 푸는 것과 같은 문제인데,
Skeleton은 끄는 경우가 더 잦아서 옵션으로 뒀어요.
