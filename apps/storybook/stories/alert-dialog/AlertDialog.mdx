되돌릴 수 없는 결정을 확인받는 모달이에요. 삭제나 탈퇴처럼 취소와 확인 중
하나를 반드시 골라야 할 때 써요. 바깥을 눌러도 닫히지 않아요.

## 언제 쓰는가

- 삭제나 탈퇴처럼 되돌릴 수 없는 동작을 실행하기 직전에 한 번 더 물을 때.

## 언제 쓰지 않는가

- 취소해도 손해가 없는 일반 작업은
  [Dialog](?path=/docs/overlays-dialog--docs)를 쓰세요. 폼이나 설정이 여기에
  해당해요.
- 제목, 설명, 확인/취소 버튼 둘만 필요하다면
  [ConfirmDialog](?path=/docs/patterns-confirmdialog--docs)를 쓰세요. 아래
  조립을 호출 한 번으로 대신해 줘요. 확인 버튼이 둘 이상이거나 본문이 설명 한
  줄을 넘을 때만 `AlertDialog`를 직접 조립하세요.

## 사용법

취소 버튼은 `AlertDialog.Close`에 `render`로 넘겨서 만들어요. 확인 버튼은
`Close`가 아니라 일반 `Button`이에요. 실제 동작을 먼저 하고 직접 닫으세요.

<Canvas of={AlertDialogStories.Playground} />

```tsx
<AlertDialog.Root open={open} onOpenChange={setOpen}>
  <AlertDialog.Trigger render={<Button variant="destructive">거래 삭제</Button>} />
  <AlertDialog.Portal>
    <AlertDialog.Backdrop />
    <AlertDialog.Viewport>
      <AlertDialog.Popup>
        <AlertDialog.Header>
          <AlertDialog.Title>거래를 삭제할까요?</AlertDialog.Title>
          <AlertDialog.Description>삭제한 거래는 되돌릴 수 없습니다.</AlertDialog.Description>
        </AlertDialog.Header>
        <AlertDialog.Footer>
          <AlertDialog.Close render={<Button variant="outline">취소</Button>} />
          <Button variant="destructive" onClick={() => { deleteAndClose() }}>삭제</Button>
        </AlertDialog.Footer>
      </AlertDialog.Popup>
    </AlertDialog.Viewport>
  </AlertDialog.Portal>
</AlertDialog.Root>
```

`Header`와 `Footer`는 Dialog와 같은 모양을 내는 레이아웃 그룹이에요. `Header`는
제목 다음 세로 간격을, `Footer`는 오른쪽 정렬한 버튼 줄을 그려요.

## 주의할 점

### 우상단 X 버튼은 없어요

`AlertDialog.Close`에는 Dialog의 X 스타일이 없어요. 취소 버튼으로만 닫는
통로를 두세요. 실수로 닫히면 안 되는 결정이라 바깥 클릭으로도 닫히지 않아요.

## 키보드

Dialog와 같아요. 열리면 포커스가 안으로 들어가고, Tab을 눌러도 포커스가 밖으로
나가지 않으며, Esc를 누르면 닫히고 포커스가 트리거로 돌아와요.

## 배경

[Dialog](?path=/docs/overlays-dialog--docs)와 같은 배경, 테두리, 그림자를 써요.
`Header`와 `Footer`는 Base UI에 대응하는 파트가 없어서 DS가 더한 레이아웃
그룹이고, Dialog와 한 곳에서 함께 정의해 둘이 같은 모양을 내요.
