본문과 제목을 그린다. `Text`는 태그를, `Heading`은 태그(`level`)와 크기(`size`)를 따로 받는다 — 둘 다 Base UI 뒤가 없는 자체 스타일 primitive다.

## 언제 쓰는가

- 임의 `text-*` 유틸리티를 컴포넌트 밖에서 직접 쓰는 대신, 타이포 스케일 이름을 `size`로 받아 앱에 크기가 흩어지지 않게 한다.
- `Heading`은 문서 구조(제목 레벨)와 시각 크기가 다른 자리 — 카드 안의 단독 제목처럼 — 를 `level`과 `size`를 따로 줘서 표현한다.

## 언제 쓰지 않는가

- **`size` 밖의 크기가 필요할 때.** 아홉 이름이 전부다 — Foundations 타이포 챕터 밖의 크기가 필요하면 그 축이 부족한 것이지 `className`으로 우회하지 않는다.
- **페이지의 유일한 h1일 때.** 페이지 제목은 Page shell(#286)이 진다 — 본문 안에서 `Heading`은 `level={2}`부터 시작한다.

## 크기

크기 이름은 Foundations 타이포 챕터의 이름과 같다 — 신규 어휘는 0개다.

## Heading — 레벨과 크기

`level`(1~6)이 렌더되는 태그를, `size`가 시각 크기를 정한다. `size`를 생략하면 `level`의 기본 크기를 쓴다.

## 톤

`Text`·`Heading`의 `tone`은 `Badge`·`Alert`가 이미 쓰는 `tone` 어휘와 같은 이름을 쓴다 — 같은 축이 컴포넌트마다 다른 어휘를 가지면 소비처가 매번 새로 배워야 한다([#365](https://github.com/flameware/massive-design/issues/365) user story 8, [#368](https://github.com/flameware/massive-design/issues/368)). 기본값은 `inherit` — 색 클래스를 하나도 내지 않고 부모의 색을 그대로 물려받는다([#366](https://github.com/flameware/massive-design/issues/366)이 게시 인스턴스 14개 전수 확인 뒤 확정: `Text`는 임의 색 위에 얹히는 범용 primitive다). 값 이름은 넷 중 실측 수요가 있는 셋뿐이다 — `accent`·`success`·`warning`·`outline`은 `Badge`에만 있고 여기 수요가 0이라 열지 않는다.

| 값 | 클래스 | Text·Heading 수요 |
| --- | --- | --- |
| `inherit`(기본) | (없음) | — |
| `neutral` | `text-default` | 12자리(Text 1·Heading 2 + 기본 텍스트 색) |
| `danger` | `text-danger` | 4자리(Text 3·Heading 1) |
| `muted` | `text-muted` | 10자리(Text만) |

### 세 컴포넌트·Alert의 `tone` 어휘

값 이름은 겹치는 자리에서 전부 같다 — 컴포넌트마다 실측 수요가 있는 값만 연다(rules.md 축과 이름 공간: 값을 여는 데도 실측 수요가 근거다).

| 값 | Text·Heading | Badge | Alert |
| --- | --- | --- | --- |
| `neutral` | ✓(`text-default`) | ✓(`bg-neutral-soft text-default`) | ✓(`bg-neutral-soft`) |
| `danger` | ✓(`text-danger`) | ✓(`bg-danger-soft text-danger`) | ✓(`bg-danger-soft`) |
| `warning` | — | ✓ | ✓ |
| `accent` | — | ✓ | — |
| `success` | — | ✓ | — |
| `outline` | — | ✓(면 없음) | — |
| `muted` | ✓(`text-muted`, Text만) | ✓(`bg-neutral-muted text-default`) | — |
| `inherit` | ✓(기본, Text·Heading만) | — | — |

## Heading — 굵기

`weight`는 `Heading`에만 있다 — `Text`는 실측 수요가 없다. 기본은 지금까지 하드코딩돼 있던 `semibold`, 실측 수요(3자리)가 연 값은 `bold`다.
