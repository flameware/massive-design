본문과 제목을 그려요. 크기를 `text-*` 유틸리티로 직접 쓰는 대신 타이포 스케일
이름을 `size`로 받아서, 앱 곳곳에 제각각인 크기가 생기지 않게 해요.

## 언제 쓰는가

- 본문 글에 크기 이름을 주고 싶을 때. `size`가 받는 아홉 가지 이름은
  Foundations 타이포 챕터의 이름과 같아요.
- 문서 구조의 제목 레벨과 보이는 크기가 다를 때. 카드 안의 단독 제목처럼요.
  `Heading`에 `level`과 `size`를 따로 주면 돼요.

## 언제 쓰지 않는가

- 아홉 가지 `size` 이름 밖의 크기가 필요할 때는 `className`으로 우회하지
  마세요. 타이포 스케일에 그 크기가 아직 없다는 뜻이에요.
- 페이지의 유일한 `h1`에는 쓰지 마세요. 페이지 제목은 `PageShell`이
  담당해요. 본문 안에서 `Heading`은 `level={2}`부터 시작해요.

## 톤

`tone`이 글자 색을 정해요. 기본값은 `inherit`이라 색 클래스를 하나도 내지
않고 부모의 색을 그대로 물려받아요.

| 값 | 클래스 | 언제 쓰나 |
| --- | --- | --- |
| `inherit`(기본) | (없음) | 부모의 색을 그대로 물려받을 때 |
| `neutral` | `text-default` | 기본 본문 색을 직접 지정할 때 |
| `danger` | `text-danger` | 오류나 경고 문구일 때 |
| `muted` | `text-muted` | 부가 설명처럼 덜 강조할 때 |

### `Badge`, `Alert`와 겹치는 값

`tone` 값 이름은 여러 컴포넌트에서 같은 뜻으로 써요. 컴포넌트마다 실제로
필요한 값만 열려 있어요.

| 값 | Text·Heading | Badge | Alert |
| --- | --- | --- | --- |
| `neutral` | ✓(`text-default`) | ✓(`bg-neutral-soft text-default`) | ✓(`bg-neutral-soft`) |
| `danger` | ✓(`text-danger`) | ✓(`bg-danger-soft text-danger`) | ✓(`bg-danger-soft`) |
| `warning` | 없음 | ✓ | ✓ |
| `accent` | 없음 | ✓ | 없음 |
| `success` | 없음 | ✓ | 없음 |
| `outline` | 없음 | ✓(면 없음) | 없음 |
| `muted` | ✓(`text-muted`) | ✓(`bg-neutral-muted text-default`) | 없음 |
| `inherit` | ✓(기본) | 없음 | 없음 |

## 배경

Base UI에 대응하는 컴포넌트가 없어서 DS가 직접 만든 컴포넌트예요.

`tone` 기본값이 `inherit`인 이유는 `Text`가 임의의 배경색 위에 얹히는 범용
컴포넌트이기 때문이에요. `tone`과 `weight`에 열려 있는 값은 실제로 쓰이는
것만 추린 결과예요. 같은 옵션이 컴포넌트마다 다른 이름을 갖지 않도록
`Badge`, `Alert`와 값 이름을 맞췄어요.
