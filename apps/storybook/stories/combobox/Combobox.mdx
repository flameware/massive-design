입력으로 목록을 좁혀 가며 하나를 고르는 컨트롤이에요. 항목이 서버에서 늦게
와도 같은 방식으로 써요.

## 언제 쓰는가

- 목록이 길어서 입력으로 좁혀야 고를 수 있을 때. 종목 검색처럼 코드나 이름으로
  찾는 경우예요.
- 항목이 서버에서 비동기로 올 때. `items`에 로딩 중에는 빈 배열을, 응답이 오면
  채운 배열을 그대로 넘기면 돼요.

## 언제 쓰지 않는가

- 목록이 몇 개뿐이고 필터가 필요 없다면 `Select`를 쓰세요.
- 목록에서 고르는 것이 아니라 자유 텍스트만 받는다면 `Input`이에요.

## 사용법

`Combobox.Root` 아래에 `Input`, `Popup`, `List`, `Item`, `Empty`, `Status`를
조립해요. `Combobox.Popup`은 팝업의 위치 옵션(`side`, `align`, `sideOffset`,
`alignOffset`, `anchor`)만 받고 나머지는 기본값을 써요.

```tsx
import { Combobox } from "@flameware/ui/combobox"
import { Field } from "@flameware/ui/field"

<Field.Root name="symbol">
  <Field.Label>종목 검색</Field.Label>
  <Combobox.Root items={stocks} itemToStringLabel={(s) => `${s.name} ${s.symbol}`}>
    <Combobox.Input placeholder="종목명 또는 코드" />
    <Combobox.Popup>
      <Combobox.Empty>검색 결과가 없습니다</Combobox.Empty>
      <Combobox.List>
        {(stock) => (
          <Combobox.Item key={stock.symbol} value={stock}>
            {stock.name} {stock.symbol}
          </Combobox.Item>
        )}
      </Combobox.List>
    </Combobox.Popup>
  </Combobox.Root>
</Field.Root>
```

`Field.Root` 안에 두면 라벨, 설명, 오류가 `Combobox.Input`에 자동으로
연결돼요. 연결 방식은 `Input`과 같아요.

### 필터

기본 필터를 그대로 써요. 대소문자와 발음 구별 기호를 무시하고 부분일치로
비교하며, 비교 대상은 `itemToStringLabel`이 돌려주는 문자열이에요. 종목명과
코드 둘 다로 찾게 하려면 그 함수가 둘을 합친 문자열을 돌려주면 돼요. 다른
규칙이 필요하면 `filter` prop으로 바꿀 수 있어요.

### 비동기 항목과 빈 결과

`items`는 앱이 관리해요. 로딩 중에는 빈 배열을, 응답이 오면 채운 배열을 그대로
넘기세요. 로딩 문구는 `Combobox.Status`로 보여 주면 화면 낭독기에도 알려
줘요. 결과가 정말 없을 때는 `Combobox.Empty`가 스스로 나타나요.

### 목록에 없는 값 받기

목록이 후보를 다 보여 주지 못할 때가 있어요. 예를 들어 종목 검색이 아직
상장되지 않은 종목명을 받아야 하는 경우예요. 이때는 `Combobox.Input`에
`onFreeformSubmit`을 주세요. 필터 결과가 0개인 채로 Enter를 누르면 지금 입력한
텍스트로 이 콜백이 불려요. 후보가 있어서 골라 쓰는 기존 흐름은 그대로예요.

```tsx
<Combobox.Root items={stocks} itemToStringLabel={(s) => `${s.name} ${s.symbol}`} value={value} onValueChange={setValue}>
  <Combobox.Input
    placeholder="종목명 또는 코드"
    onFreeformSubmit={(name) => setValue({ manual: true, name })}
  />
  {/* … */}
</Combobox.Root>
```

Combobox는 입력한 텍스트를 그대로 넘길 뿐이라, 그 값이 무엇을 뜻하는지는 앱이
정해요. `Value` 타입을 후보 객체와 직접 입력한 값 둘 다 받도록 열어 두세요.
`onFreeformSubmit`을 주지 않으면 Enter는 팝업만 닫아요.

### 입력 칸 안에 컨트롤 두기

검색 대상을 고르는 세그먼트처럼 입력 칸 안에 컨트롤을 함께 두려면
`Combobox.InputGroup`으로 `Combobox.Input`과 그 컨트롤을 감싸세요. 테두리,
배경, 포커스 링은 그룹이 그리고, 안의 입력은 테두리 없이 남은 폭을 채워요.
후보 목록은 `anchor`를 주지 않아도 그룹 폭에 맞춰 열려요.

```tsx
<Combobox.Root items={items}>
  <Combobox.InputGroup>
    <ToggleGroup
      aria-label="시장"
      value={[market]}
      onValueChange={(next) => next[0] && setMarket(next[0])}
    >
      <Toggle value="kr">한국</Toggle>
      <Toggle value="us">미국</Toggle>
    </ToggleGroup>
    <Combobox.Input placeholder="종목명 또는 코드" />
  </Combobox.InputGroup>
  <Combobox.Popup>…</Combobox.Popup>
</Combobox.Root>
```

<Canvas of={ComboboxStories.InputGroupSegment} />

그룹 안의 `ToggleGroup`은 자기 테두리와 배경 없이 칸 안을 채워요. 항목 높이도
그룹이 정해서 `size`를 주지 않아도 되고, 주더라도 칸의 높이는 다른 입력과 같은
36px 그대로예요.

<Canvas of={ComboboxStories.InputGroupControlHeight} />

`Field.Root`의 `invalid`와 `disabled`는 그룹 전체에 보여요. 오류일 때는 그룹
테두리가 빨갛게 바뀌고, 비활성일 때는 그룹 전체가 흐려져요. 그룹 안의
`ToggleGroup`은 흐려진 칸 안에서도 키보드로 닿을 수 있으니 `disabled`를 함께
주세요.

<Canvas of={ComboboxStories.InputGroupStates} />

## 주의할 점

### 입력과 `ToggleGroup`은 `Combobox.InputGroup`에 바로 넣으세요

그룹은 바로 안에 있는 입력의 포커스를 보고 링을 그리고, 바로 안에 있는
`ToggleGroup`의 치수를 정해요. 다른 요소로 한 번 더 감싸면 포커스 링이 그룹에
나타나지 않고 `ToggleGroup`은 칸 밖에서와 같은 모양으로 그려져요. `name`을 준
`ToggleGroup`도 감싸는 요소가 하나 생기므로, 그룹 안에서는 `value`와
`onValueChange`로 값을 관리하세요.

### 목록이 열린 동안 그룹 안 컨트롤은 화면 읽기 프로그램에서 숨어요

후보 목록이 열려 있으면 입력과 목록 밖의 요소가 화면 읽기 프로그램에서
가려져요. Base UI Combobox의 기본 동작이에요. Shift+Tab으로 그룹 안 컨트롤로
돌아가면 목록이 닫히면서 다시 읽혀요.

### `Empty`와 `Status`는 조건부로 렌더하지 마세요

두 컴포넌트는 화면에 계속 붙어 있어야 제 역할을 해요. 보여 줄 내용이 없을
때는 컴포넌트 자체를 지우지 말고 children만 비우세요. 결과가 있을 때 빈 띠가
보이지 않도록 DS가 여백을 접어 둬요.

`Combobox.List`도 로딩 중에 지우지 마세요. 입력의 `aria-controls`가 그 목록을
가리키기 때문에, `items`가 비어 있어도
`<Combobox.List>{() => null}</Combobox.List>`처럼 붙여 두면 돼요.

## 배경

Base UI `Combobox` 위에 얹었어요. 입력, 필터, 키보드 탐색, Field 연결은 Base
UI가 처리하고, DS는 색과 간격을 입히고 Base UI의 `Portal`, `Positioner`,
`Popup` 셋을 `Combobox.Popup` 하나로 접었어요.

`Combobox.InputGroup`은 Base UI Combobox의 `InputGroup` 파트를 감싼 것이에요.
`Input`이나 `Select`에 붙이는 범용 입력 그룹은 제공하지 않아요.
