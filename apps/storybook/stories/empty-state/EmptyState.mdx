"…없습니다" 자리를 한 모양으로 묶는다. Base UI 뒤가 없는 자체 스타일 패턴이다 — 아이콘·제목·설명·행동 버튼 넷을 하나의 이름 아래 둔다.

## 언제 쓰는가

- 목록·표가 비어 사용자에게 "왜 비었는지"와 "다음에 뭘 할 수 있는지"를 같이 보여줄 때 — 거래 내역, 검색 결과.

## 언제 쓰지 않는가

- **로딩 중일 때.** 아직 데이터를 기다리는 자리는 `Skeleton`이 진다 — EmptyState는 요청이 끝났고 결과가 0건임을 확인한 뒤에만 놓는다.
- **오류일 때.** 요청이 실패한 자리는 `Alert`가 진다 — 빈 것과 실패한 것은 다른 사실이다.

## 파트

`EmptyState.Root`·`Icon`·`Title`·`Description`·`Action` — 네임스페이스형 API다. `Icon`·`Action`은 옵셔널이라 아이콘 없이·행동 버튼 없이도 유효하다.

## 제목·설명이 한 덩어리로 읽힌다

`Root`가 `Title`·`Description`이 낸 id를 `aria-labelledby`·`aria-describedby`로 받는다 — 스크린 리더가 블록에 들어오면 제목과 설명을 이어서 읽는다. `role="group"`을 쓴다: 접근성 이름·설명 계산은 받되 `role="region"`처럼 페이지 랜드마크를 새로 열지 않는다.

## 아이콘

`EmptyState.Icon`은 자리·색만 진다 — 이름은 언제나 밖에 있다(`Icon`이 기본으로 `aria-hidden`을 건다, icon.tsx 참고). `<Icon icon={Inbox} />` 하나만 넘기면 40px 크기로 그린다.

## 행동 버튼

`EmptyState.Action`은 위쪽 간격만 준다 — `Button`을 직접 import해 기본 variant를 먹이지 않는다(Card.Footer와 같은 이유, rules.md 의존성과 base). 24×24 포인터 하한은 `Button`이 이미 진다.
