관련된 내용을 하나의 카드로 묶어 주변과 구분해요. 상태도 상호작용도 없어서
그리기만 하는 컴포넌트예요.

## 언제 쓰는가

- 관련된 정보를 한 덩어리로 묶어 주변과 구분할 때. 요약 카드, 목록의 한
  항목이 여기에 해당해요.
- 제목 아래에 행 목록을 카드 가장자리까지 붙여 보여 줄 때. 아래 목록 카드를
  쓰세요.
- `Header`, `Body`, `Footer` 중 필요한 것만 골라 쓸 때. 셋 다 선택이라
  `Body` 하나만으로도 돼요.

## 언제 쓰지 않는가

- 카드 전체가 눌리는 버튼이나 링크여야 한다면 `Card`만으로는 부족해요.
  `Button`을 `render`로 감싸거나 카드 안에 따로 버튼을 두세요. `Card` 자체는
  클릭 핸들러도 role도 갖지 않아요.
- `SummaryCard` 같은 새 컴포넌트를 만들지 마세요. 아래 부분들로 조립하세요.

## 여백

카드 안쪽 여백은 화면 폭이 `sm`(640px)보다 좁으면 16px, 그 이상이면 24px이에요.
`Header`, `Body`, `Footer`의 좌우 여백과 `Root`의 위아래 여백이 모두 이 값을
따라요. 부분 사이 간격(24px)은 화면 폭과 관계없이 같아요.

<Canvas of={CardStories.Narrow} />

여백을 바꾸려면 `Root`에서 CSS 변수 `--ds-card-padding` 하나만 바꾸세요. 모든
부분이 함께 바뀌고, 화면 폭과 관계없이 그 값이 쓰여요.

```tsx
<Card.Root className="[--ds-card-padding:--spacing(3)]">…</Card.Root>
```

<Canvas of={CardStories.CustomPadding} />

부분마다 `px-*`를 덮어쓰거나 `Root`에 `p-*`를 더하지 마세요. `Root`의 `p-*`는
부분의 여백을 대신하지 않고 그 위에 더해져서, 좌우 여백이 두 배 가까이 돼요.

## 목록 카드

`variant="list"`는 제목 아래에 행 목록이 카드 가장자리까지 붙는 모양이에요.
행은 `Card.Rows` 안에 두세요. `Card.Rows`가 행마다 카드 여백만큼 좌우 여백을
줘서, 행의 첫 글자가 제목 글자와 같은 세로선에 서요.

```tsx
<Card.Root variant="list">
  <Card.Header>
    <Card.Title>보유 종목</Card.Title>
  </Card.Header>
  <Card.Rows>
    <ListRow.Root>…</ListRow.Root>
    <ListRow.Root>…</ListRow.Root>
  </Card.Rows>
</Card.Root>
```

<Canvas of={CardStories.ListCard} />

목록 카드에서 각 부분은 이렇게 달라져요.

| 부분 | 모양 |
| --- | --- |
| `Root` | 위아래 여백과 부분 사이 간격이 없어요 |
| `Header` | 위아래 12px, 아래쪽에 구분선이 있어요 |
| `Rows` | 행마다 좌우에 카드 여백을 줘요. 행 자체의 치수는 그대로예요 |
| `Body` | 네 방향 모두 카드 여백이에요. 빈 상태나 경고처럼 행이 아닌 내용을 담아요 |
| `Footer` | 기본 카드와 같아요 |

행 사이 구분선은 그리지 않아요. 필요하면 행에 직접 테두리를 주세요.

## 그림자

기본은 그림자가 없는 평평한 모양이에요. 그림자가 필요하면 그림자
토큰(`shadow-xs`부터 `shadow-xl`까지)을 `className`으로 얹으세요.

## 배경

Base UI에 대응하는 컴포넌트가 없어서 DS가 직접 만든 컴포넌트예요. 상태와
상호작용이 없어서 서버 컴포넌트로 동작하고, 부분들은 `Root`의 `data-variant`
속성으로 모양을 정해요. 여백 기본값과 목록 카드 규칙은 Tailwind의 `components`
층에 있어서 `className`으로 준 유틸리티가 늘 이겨요.
