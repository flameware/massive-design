한 줄 텍스트 입력. `Field.Root` 안에 놓으면 라벨·설명·오류가 aria로 자동 연결된다.

## 언제 쓰는가

- 로그인·회원가입의 이메일·비밀번호 같은 한 줄 값.
- `Field.Root` 없이 홀로 써도 동작하지만, 그때는 `aria-label`을 직접 달아야 한다 — 라벨링은 소비처 몫이 된다.

## 언제 쓰지 않는가

- 여러 줄이 필요한 자리는 `Textarea`다.
- 정해진 값 중 하나를 고르는 자리는 `Select`(Phase 1의 다른 티켓)다.

## 조립

`Field.Root` 안에 두면 라벨·설명·오류가 자동으로 연결된다.

## type

HTML `type` 그대로다 — `email`·`password`처럼 브라우저의 네이티브 키보드·자동완성·검증을 그대로 받는다.

## 상태

`disabled`는 `Field.Root`에서 물려받을 수도, `Input` 자신에 직접 줄 수도 있다(`Field.Root`가 우선한다). `invalid`는 `Field.Root`의 것이고 테두리 색은 거기서 내려온 `data-invalid`를 읽는다.
