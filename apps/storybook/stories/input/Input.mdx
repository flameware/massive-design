한 줄 텍스트 입력이에요. `Field.Root` 안에 놓으면 라벨, 설명, 오류가 aria로
자동 연결돼요.

## 언제 쓰는가

- 로그인이나 회원가입의 이메일, 비밀번호 같은 한 줄 값.
- `Field.Root` 없이 홀로 써도 동작해요. 그때는 `aria-label`을 직접 달아야
  해요.

## 언제 쓰지 않는가

- 여러 줄이 필요하면 `Textarea`예요.
- 정해진 값 중 하나를 고른다면 `Select`예요.

## 사용법

`Field.Root` 안에 두면 라벨, 설명, 오류가 자동으로 연결돼요.

<Canvas of={InputStories.Playground} />

### type

HTML `type`을 그대로 받아요. `email`이나 `password`를 주면 브라우저의 키보드,
자동완성, 검증이 그대로 동작해요.

<Canvas of={InputStories.Types} />

### 상태

`disabled`는 `Field.Root`에서 물려받을 수도 있고 `Input`에 직접 줄 수도
있어요. 둘 다 있으면 `Field.Root`가 우선해요. `invalid`는 `Field.Root`에만
주며, 테두리 색이 거기서 내려온 값을 읽어요.
