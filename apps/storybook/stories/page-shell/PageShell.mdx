대시보드의 바깥 틀을 그려요. 좌우 슬롯이 있는 상단 헤더, 탭 내비게이션, 본문
최대 폭까지 한 번에 잡아 줘서 앱이 틀을 다시 짜지 않아도 돼요.

## 언제 쓰는가

- 로그인한 뒤 화면 전체를 감싸는 틀이 필요할 때. 헤더에 로고, 테마 토글,
  사용자 메뉴가 있고 그 아래 탭으로 화면을 오가는 구조예요.

## 언제 쓰지 않는가

- 탭 내비게이션이 필요 없으면 쓰지 마세요. `nav`가 필수 prop이라 화면이 하나뿐인
  곳에는 맞지 않아요. 헤더만 필요하면 헤더를 직접 조립하세요.
- 로그인 전 화면에는 쓰지 마세요. 이 틀은 인증 뒤의 대시보드용이에요.

## 사용법

`header`에 좌우 슬롯을, `nav`에 탭 목록을 주고, 본문을 `children`으로 넘겨요.
탭은 [Tabs](?path=/docs/navigation-tabs--docs)를 그대로 써서 그리기 때문에
화살표 키로 옮기면 곧바로 선택되는 동작이 똑같이 적용돼요.

라우트 링크가 필요하면 항목마다 `render`로 앵커나 Next의 `Link`를 넘기세요.

```tsx
<PageShell
  header={{ left: <Logo />, right: <ThemeToggle theme={theme} onThemeChange={setTheme} /> }}
  nav={{
    value: pathname,
    onValueChange: () => {}, // 라우팅이 실제 전환을 맡으므로 비워 둬요
    items: [
      { value: "/portfolio", label: "포트폴리오", render: <Link href="/portfolio" /> },
      { value: "/history", label: "히스토리", render: <Link href="/history" /> },
    ],
  }}
>
  {children}
</PageShell>
```

### 데스크톱과 모바일

헤더, 탭, 본문이 같은 최대 폭 안에서 정렬돼요. 기본값은 `max-w-6xl`이고
`contentWidthClassName`으로 바꿀 수 있어요. 좁은 화면에서는 탭 목록이 가로
스크롤로 넘어가고 헤더 오른쪽 슬롯은 줄어들지 않아요.

## Props

`header.left`와 `header.right`는 아무 노드나 받아요. `children`이 본문이에요.

`nav`는 `Tabs.Root`처럼 값을 밖에서 주는 컴포넌트예요. `value`와
`onValueChange`를 앱이 관리하세요. 라우팅 상태와 맞물리는 값이기 때문이에요.
