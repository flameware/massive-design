모바일 목록의 한 줄을 그려요. 주 텍스트, 보조 텍스트, 오른쪽 값 세 부분으로
이루어져요.

## 언제 쓰는가

- 폭이 좁은 화면에서 한 항목을 "이름 + 보조 정보 + 값" 한 줄로 보여 줄 때.
  보유 종목이나 거래 이력 목록이 여기에 해당해요.

## 언제 쓰지 않는가

- 여러 열을 나란히 비교해야 하면 [Table](?path=/docs/data-display-table--docs)을
  쓰세요.
- 행 전체를 누를 수 있어야 할 때는 그대로 쓰지 마세요. `ListRow`는 클릭
  핸들러도 role도 갖지 않아요. `Button`을 `render`로 감싸거나 `Root`를
  `<a>`로 바꿔 쓰세요.

## 사용법

`ListRow.Root`, `Group`, `Primary`, `Secondary`, `Value` 다섯 파트를 조립해서
써요. 흔한 조합은 `Root > (Group > Primary + Secondary) + Value`예요.

<Canvas of={ListRowStories.Playground} />

<Canvas of={ListRowStories.List} />

파트는 모두 생략할 수 있어요. 보조 텍스트나 값이 없는 항목은 해당 파트를 빼고
쓰면 돼요.

## Props

`ListRow.Root`는 별도의 옵션이 없어요. 모든 파트가 일반 `<div>` 속성을 그대로
받아요.

## 배경

Base UI에 대응하는 컴포넌트가 없어서 DS가 직접 만든 컴포넌트예요. 행을 누를 수
있게 만드는 일을 앱에 맡기는 것은 `Card`와 같은 판단이에요.
