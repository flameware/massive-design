# 상태

어떤 컴포넌트를 지금 써도 되는지 한눈에 보는 표예요. 각 컴포넌트가 스스로
선언한 값을 그대로 읽어서 만들어져요.

## 상태 네 가지

- `planned`: 만들기로 했지만 아직 코드가 없어요.
- `preview`: 쓸 수 있지만 모양이 바뀔 수 있어요. minor 버전을 올릴 때 손볼
  수 있다고 생각하고 쓰세요.
- `stable`: 깨는 변경은 major 버전에서만 나요.
- `deprecated`: 대신 쓸 것이 있어요. 새로 쓰지 마세요.

## 주의할 점

### `planned`은 표에 나오지 않아요

표는 스토리가 있는 컴포넌트만 실어요. 목록이 스토리 파일을 훑어서 만들어지기
때문에, 빈 스토리라도 세우기 전까지는 표에 나타나지 않아요. 무엇이 계획돼
있는지는 이 표가 아니라
[Phase 1 스펙](https://github.com/flameware/massive-design/issues/275)에
있어요.

## 컴포넌트가 상태를 선언하는 법

스토리 메타의 `parameters.ds`에 `status`와 `since`를 적어요. 분류와 이름은
따로 적지 않고 `title`에서 읽어요.

```tsx
const meta = {
  title: "Actions/Button",
  component: Button,
  parameters: { ds: { status: "preview", since: "0.1.0" } },
} satisfies Meta<typeof Button> & ComponentMeta
```

## 배경

분류와 이름의 사본을 하나 더 두지 않는 이유는 사이드바가 묶는 문자열과 이
표가 읽는 문자열이 같아야 둘이 어긋나지 않기 때문이에요. `title`의 첫 마디가
정해진 열 개 분류 중 하나인지는 `satisfies`가 컴파일할 때 확인해요.
