# 터치 대상 크기 규칙과 검증 규약 개정 맵 완료 기록

맵 [#111](https://github.com/flameware/massive-design/issues/111) · 결정은 [ADR-0020](../adr/0020-pointer-target-size-is-borne-by-the-hit-area.md) · 규칙은 [`../agents/rules.md`](../agents/rules.md)

## What the map reached

The **터치 대상 크기 규칙과 검증 규약 개정** map ([#111](https://github.com/flameware/massive-design/issues/111)) reached its destination: **every pointer target in the catalog satisfies the 24×24 CSS px floor, or is named in the exception list with its reason.** Seven tickets. The catalog had never set a minimum target size — `touch`·`coarse` appeared only on gesture code — so the map set it once, catalog-wide, at WCAG 2.5.8 (AA), and put the floor on the **hit area** rather than the visual box, so no published dimension moved and the 43 Figma sets stayed valid.

The last re-measurement ([#249](https://github.com/flameware/massive-design/issues/249)) reads `pointer-gate` regression 0 · undeclared overlap 0. Known gap 93, all outside the map: the Sidebar icon mode that was never drawn ([#250](https://github.com/flameware/massive-design/issues/250), fixed alongside this record) and reference-story occlusion, which is a property of the story layout, not of the component.

- [예외 목록 확정 — 규칙이 닿지 못하는 자리와 그 이유](https://github.com/flameware/massive-design/issues/231) — **five exceptions**: two structural clips (Scroll Area thumb·scrollbar), one externally owned (Resizable handle, `hitAreaMargins`), two WCAG 2.5.8 *Equivalent* (labels, Slider track — conditional on #230 lifting Checkbox·Radio·Switch·thumb to 24, since met). The *Inline* exception for labels was rejected. Canonical: [`docs/research/pointer-target-exceptions-2026-09.md`](../research/pointer-target-exceptions-2026-09.md), consumed by the gate as `docs/research/pointer-target-exceptions.json`.
- [규칙 적용 — 미달 포인터 대상에 히트 영역 부여](https://github.com/flameware/massive-design/issues/230) — 16/20 px families (8 kinds) plus Sidebar rail widened to 24 with `after:` (or `before:` where `after:` already draws a hover line), centre-symmetric. Two implementation traps the instrument caught: an absolute pseudo-element's containing block is the padding box, so border width had to be compensated; and widening one axis alone collapses the other to 0 unless `inset-*-0` is explicit. `classify.mjs` gained `before → ignore:`.
- [규칙 적용 ② — 한 줄 텍스트 계열(22.4px)의 미달 대상에 히트 영역 부여](https://github.com/flameware/massive-design/issues/249) — Toast close·action, Breadcrumb link, Sidebar menu-action to 24×24 with the same mechanism; cause (line-height·padding) and mechanism are separate, so one mechanism served all four. Baseline TSV regenerated by re-measurement.
- [실측 게이트 — 하한 미달과 미신고 겹침을 문다 (CI 승격은 보류)](https://github.com/flameware/massive-design/issues/232) — `bun run pointer-gate` on top of the #228 instrument; both failures judged as a **diff against the committed baseline**. The first design (asking for `after:` styles) mis-fired 172 times on reference-story noise and was discarded. Policy table unchanged (decision 6). **Not on CI** — promotion waits on a repeated regression, an event, never a date.
- [검증 규약 개정 — 뷰포트 확인 항목과 확인표 예외의 명문화](https://github.com/flameware/massive-design/issues/233) — a fifth human check in `design-system-sync.md`, "뷰포트 확인 — 포인터 대상 크기", run **only in generations that touch a pointer-target slot**, and the runbook's "the checklist is never narrowed" principle now names its two explicit exceptions. The 44 px AAA figure lives in `CONTEXT.md` as consumer advice, not contract.

## What the fog resolved into

- **CI promotion of the gate** — deferred, by decision 6 of the ADR. The trigger is a regression reproducing across generations. Until then `pointer-gate` is a tool a maintainer runs when a pointer-target slot changes, and the runbook says when.
- **Piercing the two `overflow` clips** — a structural change to Scroll Area, a different kind of effort. The exception list is its population; nothing is open for it.
- **Figma knowing the rule** — it does not, and by decision 6 it need not: `after`/`before` stay `ignore:` because there is nothing to draw. Revisit only if a static comp ever needs a hit area.

## Out of scope

- **Sidebar icon mode** ([#250](https://github.com/flameware/massive-design/issues/250)) — the four icon-mode gaps the instrument found were not a rule failure but an unimplemented configuration state; fixed as its own change, not by this map.
- **Figma Sync** ([#138](https://github.com/flameware/massive-design/issues/138)) and npm publishing.
